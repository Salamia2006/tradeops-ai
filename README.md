# TradeOps AI — демонстрационный MVP

Сервис сопровождения внешнеторговой сделки: документы → проверки → подтверждение → симуляция платежа → сверка → кейс отклонения.

## Демо

Сайт публикуется через GitHub Pages из ветки main, папка / (root). В корне находятся готовые index.html, JavaScript и CSS. Вход в ChatGPT посетителю не требуется.

## Что попробовать

1. Нажмите «Разобрать кейс»: обязательство 380 000 CNY, зачисление 378 500 CNY, недоплата 1 500 CNY. Комиссия — гипотеза, обязательство автоматически не закрывается.
2. Изучите документы, извлечённые поля и историю.
3. Передайте кейс в демо-очередь и скачайте JSON.
4. Пройдите сценарий «Обычный платёж» и сверку полного зачисления.
5. Проверьте сценарий «Ошибка в инвойсе» и раздел «Архитектура MVP».

## Исходники и запуск

[Полные исходники, тесты и документация — TradeOps-Source.zip](TradeOps-Source.zip). Распакуйте архив и откройте папку tradeops-ai.

Архив содержит React/TypeScript интерфейс, общее ядро бизнес-правил, браузерный адаптер IndexedDB, серверный HTTP API и SQLite/D1, миграции, примеры документов и сценарий защиты. Подробности — README.md и docs/ внутри архива.

Для серверного демо: Node.js 22.13+, затем `npm install` и `npm run demo`. Для проверки: `npm test`, `npm run typecheck`. Для сборки браузерной версии: `npm run build:pages`.

## Границы MVP

В публичном демо данные сохраняются только в браузере посетителя (IndexedDB). Сервисы ВТБ, реальные платежи, LLM и OCR не подключены. Извлечение работает по правилам для структурированного TXT. Все стартовые данные вымышлены. Интерфейсы банковских адаптеров — проектные контракты для будущей интеграции.

Проверены 26 автоматических тестов бизнес-правил и браузерного хранилища, TypeScript и сборка Pages. Экономический эффект ещё требует проверки на пилоте.
